# 生产准备检查清单

本文档记录当前真实扫描链路在受控环境下的验证结果，以及接入真实商品前仍需完成的人工检查。它不代表已经连接真实电商站点或切换生产模式。

## 已验证

- [x] 商品清单校验：仅允许 DE/IT，拒绝重复市场 SKU，过滤禁用商品。
- [x] Playwright 适配器：页面导航、就绪选择器、截图失败均映射为 `technical_failure`。
- [x] ROI：相对比例裁剪、CSS 选择器优先、边界裁剪和空区域拒绝。
- [x] OCR：仅接收 ROI，支持英/德/意词库、大小写、空格、标点、连字符和重音归一化。
- [x] 重试：技术故障同周期最多 3 次，健康和库存风险不重试。
- [x] MySQL 仓储：SQLAlchemy 模型、异步 Session、Alembic 初始迁移和 SQLite 合同测试。
- [x] 调度：单进程每小时入口，启用商品最多 3 个并发，单商品超时转技术故障。
- [x] 证据生命周期：健康截图替换清理、未处理异常保留 3 天、已处理异常人工删除。
- [x] Cookie：仅保存名称、域名、路径、过期时间、存在性和哈希摘要。
- [x] API 与页面：真实模式返回 OCR、时间、错误和截图引用；Demo 模式仍可演示。
- [x] 受控集成：假页面 + 假 OCR 完成健康和技术故障闭环，技术故障不创建库存风险告警。

## 切换前必须完成

1. 安装并固定 Tesseract 可执行程序及 `eng`、`deu`、`ita` 语言包，使用授权截图做识别率基准。
2. 配置 MySQL 连接串、连接池参数和迁移执行方式；使用备份和恢复演练验证回滚。
3. 为每个 DE/IT 平台页面确认就绪选择器、ROI 配置和加购词库，先用少量明确授权的商品手动验收。
4. 确认截图目录权限、3 天异常证据清理任务和人工删除流程。
5. 验证每小时任务的超时、重启和回退到 `DemoScanner` 路径。
6. 确认真实模式不启用 `/api/products/{id}/demo-result`，并检查日志、页面和数据库中没有完整 Cookie 或凭据。

## 当前未决项

- Tesseract 系统安装方式和语言包来源尚未确定；当前 Python 包已安装，但系统二进制不可用。
- MySQL 服务已在本机运行，项目尚未使用真实账号连接或执行生产迁移。
- 真实站点页面结构、登录态和反爬限制尚未做人工验收。
- 飞书 Webhook、Kafka 和分布式执行仍不在当前范围。
